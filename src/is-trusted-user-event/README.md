# isTrustedUserEvent

A utility function to check if an event was generated by a genuine user interaction.

## Description

The `isTrustedUserEvent` function checks the `isTrusted` property of an event to determine if it was generated by a real user action or programmatically triggered.

## Usage

```javascript
import { isTrustedUserEvent } from "https://cdn.jsdelivr.net/gh/engr-lukman/js-utils-library@main/src/is-trusted-user-event/index.js";

// Button click handler
button.addEventListener('click', (event) => {
  if (isTrustedUserEvent(event)) {
    console.log("Real user clicked the button");
    // Safe to perform sensitive operations
  } else {
    console.log("Programmatic click detected");
    // May want to ignore or handle differently
  }
});

// Form submission
form.addEventListener('submit', (event) => {
  if (!isTrustedUserEvent(event)) {
    event.preventDefault();
    console.log("Blocked programmatic form submission");
    return;
  }
  // Process form normally
});

// Security check for sensitive actions
function handlePayment(event) {
  if (!isTrustedUserEvent(event)) {
    throw new Error("Payment must be initiated by user action");
  }
  // Process payment
}
```

## Parameters

- `event` (Event): The event object to check

## Returns

- `boolean`: `true` if the event is trusted (real user interaction), `false` otherwise

## Trusted vs Untrusted Events

**Trusted Events (isTrusted: true):**
- Real mouse clicks
- Actual keyboard presses
- Touch interactions
- System-generated events

**Untrusted Events (isTrusted: false):**
- `element.click()` programmatic calls
- `element.dispatchEvent()` synthetic events
- Events created with `new Event()`
- Bot or script-generated events

## Security Considerations

- **Pop-up Blockers**: Browsers may block pop-ups from untrusted events
- **File Downloads**: Some browsers restrict downloads from untrusted events
- **Clipboard Access**: May require trusted events
- **Full-screen API**: Often requires trusted user gesture

## Notes

- Part of the DOM Event specification
- Supported by all modern browsers
- Cannot be spoofed or overridden by scripts
- Essential for preventing automated abuse
